02. Problem Statement & Motivation

Understanding the clinical gaps in current renal diagnosis workflows

🚨 Current Siloed Workflow & Challenges
  • Time Intensive: Manual interpretation of multi-slice CT scans causes clinical delays.
  • Lack of Spatial Mapping: Standalone classification lists categories but fails to map pathology boundaries.
  • Black-Box Predictions: High-accuracy deep models lack explainability, hindering clinical trust.
  • Separated Context: Patient clinical notes and imaging data are processed in disconnected systems.
  • Inaccurate Assessment: Qualitative staging lacks exact volumetric or area ratio measurements.
  • Tool Disjointedness: Multiple separate models do not provide a unified diagnostic workflow.
💡 Proposed Integrated Framework (NephroVision)

Establish a single consolidated AI pipeline connecting image vision with generative medical advice:

  • CT Classification via PCSA-KidneyNeXt module (99.92% Acc).
  • Explainability via target layer Grad-CAM visual heatmaps.
  • Localization via conditional YOLOv11 segmentation routing.
  • Quantification via OpenCV contour pixel ratio calculations.
  • Entity Parsing via Biomedical NER from clinical history text.
  • Generative Advisory using DeepSeek API context-aware diets.
  • Interactive Graphics via Plotly 3D spatial reconstructions.

05. End-to-End Data Flow

Chronological 17-step pathway transforming raw inputs to clinical advisories

🔄 Sequential Diagnostic Stepper
1
Input Ingestion: Ingest CT slice image and clinical history paragraph.
2
RGB Conversion: Convert input grayscale CT scan matrices to 3-channel RGB.
3
Spatial Resize: Clamps spatial height and width resolution to 224 × 224 pixels.
4
Tensor conversion: Converts preprocessed NumPy arrays into float PyTorch tensors.
5
Normalization: Standardizes tensors using ImageNet mean/standard deviation.
6
PCSA Inference: Primary classifier predicts categorical class probabilities.
7
Grad-CAM: Computes gradient backpropagation relative to the target feature map layer.
8
Model Routing: Directs Tumor class → Tumor YOLO, Cyst class → Cyst YOLO.
9
Mask Generation: Router executes inference to yield polygon boundary masks.
10
Contour Extraction: Extracts closed coordinate polygon outlines from YOLO masks.
11
Area Computation: Sums total pixel areas of kidney contours and pathology contours using OpenCV.
12
Pathology Ratio: Computes ratio to check if tissue replacement exceeds alert thresholds.
13
NER Tokenization: Passes clinical notes through the Hugging Face transformer pipeline.
14
Extraction & Cleaning: Cleans WordPiece token boundaries and filters duplicate entities.
15
Context Compilation: Builds the dictionary of clinical symptoms and diagnostic facts.
16
DeepSeek Advisory: Combines notes, stats, and ratio to generate lifestyle recommendations.
17
UI Composition: Renders all visual and textual results in the final dashboard.
📐 Pathology Ratio Calculation

Calculated automatically from segmentation mask pixel counts using OpenCV contour summation:

Ratio (%) =
(Pathology Area / Kidney Area) × 100
⚠️ Threshold Rules (Alert Trigger)
  • Ratio > 30%: Alerts high risk: Recommend considering Radical Nephrectomy.
  • Ratio ≤ 30%: Alerts moderate risk: Recommend considering Partial Nephrectomy.

Note: Alert guidelines are prototype rules and not clinically validated.

06. Dataset & Data Preparation

Programmatic merger and standardization of separate segmentation sets

🔀 Smart Dataset Merger Algorithm

Cyst and Tumor segmentation labels were originally annotated in separate formats. We implemented an automated dataset merger script:

  • YAML Extraction: Reads individual dataset configurations and standardizes labels.
  • Class ID Remapping: Maps conflicting labels into a single unified key index:
    • Class 0 → kidney
    • Class 1 → tumor
    • Class 2 → cyst
  • Collision Prevention: Prefixes all file names with tumor_ and cyst_ dynamically before copying to output folders.
  • Auto-generation: Exports unified training/validation/test datasets and compiles a single data.yaml configuration file.
📁 Unified Dataset Architecture

08. AI Models and Technology Stack

Core deep learning frameworks and biomedical APIs integrated in the project

  • PCSA-KidneyNeXt: Custom multi-branch classifier capturing local (group convolutions) & global textures (PCSA attention).

09. Stage 1 — Classification and Explainable AI

Automated diagnosis and anatomical verification using the PCSA-KidneyNeXt backbone

🧠 Classifier Workflow & Hyperparameters

Images undergo hierarchical downsampling and spatial scaling. The classifier architecture utilizes:

  • Model Architecture: 4-stage KidneyNeXt blocks (96 → 192 → 384 → 768 channels).
  • Parallel Branches: Max pooling, Average pooling, 3×3 & 5×5 group convolutions.
  • Trainable Parameters: 2,114,580 weights.
  • Attention Module: Pyramid Channel & Spatial Attention (PCSA).
  • Loss / Optimizer: CrossEntropyLoss and AdamW optimization.
  • Grad-CAM target: pcsa_classifier.stage4 layer activations.

11. Stage 3 — Quantitative Pathology Analysis

Surgical boundary and tissue replacement ratio calculations via pixel contours

⚙️ Mathematical Quantification Protocol
  • Contour Area Extraction: Programmatically parses the YOLO polygon masks.
  • OpenCV Area Function: Passes coordinate arrays to cv2.contourArea() to get pixel areas.
  • Kidney Summation: Kidney Area = Σ (kidney mask pixels).
  • Pathology Summation: Pathology Area = Σ (tumor/cyst mask pixels).
  • Surgical Severity Alert: Activates a radical nephrectomy warning if tissue replacement ratio exceeds 30%.

🤖 DeepSeek Postoperative Dietary Alert

DeepSeek API analyzes patient history and the computed pathology ratio to generate three targeted dietary recommendations:

  • Diabetic Diet Control: Restrict simple carbohydrate intakes. Maintain strict glycemic index monitoring to preserve remaining kidney function post-nephrectomy.
  • Renal-Protective Focus: Restrict sodium and phosphorus intakes to control systemic blood pressure and prevent hyperfiltration in the remaining healthy kidney.
  • Clinical Alert: Highly hypervascular renal mass (suspected RCC) requires immediate oncology follow-up and dietary matching with cancer cachexia support guidelines.

⚠️ Warning: Generative AI suggestions are for research demonstration and do not replace professional medical advice.

15. Limitations, Future Work & Conclusion

Critical review and translational roadmap of the research prototype

⚠️ Identified Limitations
  • Quantitative segmentation evaluations (mAP, IoU, Dice) are still being finalized.
  • Current 3D spatial plot relies on Z-displaced 2D polygons rather than multi-slice volumetric CT stacking.
  • OpenCV area is measured in pixels rather than physical coordinates using DICOM spacing data.
  • Severity threshold rules require validation against established clinical renal guidelines.
  • Research prototype only; requires multi-institutional testing.
🔮 Planned Future Works
  • Train the unified generalist (Tumor + Cyst) model and export test matrix.
  • Delineate and map physical boundaries in mm using slice parameters from DICOM file tags.
  • Implement actual volumetric 3D reconstruction by stacking adjacent CT slices.
  • Build automated structured medical report exports for hospital information systems.
  • Deploy model in a secure web dashboard with patient data compliance framework.
🏁 Summary & Takeaways

Our framework transforms isolated diagnoses into a unified clinical assistant pipeline:

CT Scan → Classifier → Grad-CAM → YOLO → OpenCV area → NER Parsing → DeepSeek → 3D Graphics.
